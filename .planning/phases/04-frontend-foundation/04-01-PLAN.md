<!-- Contract interfaces the frontend will read from -->

From src/core/Pool.sol (key read functions):
- getReserves() -> (uint112 _reserve0, uint112 _reserve1) — pool reserves
- token0() -> address — first token address (sorted by address)
- token1() -> address — second token address
- getAmountOut(uint256 amountIn, address tokenIn) -> uint256 amountOut — swap output calculation
- balanceOf(address) -> uint256 — LP token balance (Pool IS the LP token via ERC20 inheritance)
- totalSupply() -> uint256 — total LP tokens outstanding
- MINIMUM_LIQUIDITY() -> uint256 — constant 1000

From src/core/Factory.sol:
- getPair(address, address) -> address — lookup pool by token pair
- owner() -> address — factory owner

From src/tokens/WETH.sol / MockUSDC.sol (standard ERC20):
- balanceOf(address) -> uint256
- decimals() -> uint8 (WETH=18, MockUSDC=6)
- symbol() -> string
- name() -> string
</interfaces>

  <action>
    1. From the project root, create the Next.js app:
       ```bash
       npx create-next-app@latest frontend --typescript --eslint --tailwind --app --no-src-dir --no-import-alias
       ```
       If prompted for anything, accept defaults. The key flags: --app (App Router), --typescript, --tailwind, --no-src-dir (files directly in app/).

    2. Install Web3 dependencies inside `frontend/`:
       ```bash
       cd frontend && npm install @rainbow-me/rainbowkit wagmi viem@2.x @tanstack/react-query
       ```

    3. Create `frontend/.env.local`:
       ```
       NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID=dev-project-id
       ```
       This is a placeholder. For local MetaMask (injected wallet), any non-empty string works.

    4. Create `frontend/lib/wagmi.ts` — wagmi config using RainbowKit's `getDefaultConfig`:
       ```typescript
       import { getDefaultConfig } from '@rainbow-me/rainbowkit'
       import { foundry } from 'wagmi/chains'

       export const config = getDefaultConfig({
         appName: 'SimpleDEX',
         projectId: process.env.NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID ?? 'dev-project-id',
         chains: [foundry],
         ssr: true,
       })
       ```
       IMPORTANT: `ssr: true` prevents hydration mismatch with wallet state. Only `foundry` chain (chainId 31337, Anvil) — no mainnet/sepolia.

    5. Create `frontend/app/providers.tsx` — Client component wrapping all providers:
       ```typescript
       'use client'

       import '@rainbow-me/rainbowkit/styles.css'
       import { RainbowKitProvider } from '@rainbow-me/rainbowkit'
       import { WagmiProvider } from 'wagmi'
       import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
       import { useState } from 'react'
       import { config } from '@/lib/wagmi'

       export function Providers({ children }: { children: React.ReactNode }) {
         const [queryClient] = useState(() => new QueryClient())
         return (
           <WagmiProvider config={config}>
             <QueryClientProvider client={queryClient}>
               <RainbowKitProvider>
                 {children}
               </RainbowKitProvider>
             </QueryClientProvider>
           </WagmiProvider>
         )
       }
       ```
       CRITICAL: QueryClient MUST be in useState — creating it outside the component leaks state between SSR requests.

    6. Update `frontend/app/layout.tsx` — Server Component that wraps children with Providers:
       ```typescript
       import type { Metadata } from 'next'
       import { Inter } from 'next/font/google'
       import './globals.css'
       import { Providers } from './providers'

       const inter = Inter({ subsets: ['latin'] })

       export const metadata: Metadata = {
         title: 'SimpleDEX',
         description: 'A constant product AMM for learning DeFi mechanics',
       }

       export default function RootLayout({ children }: { children: React.ReactNode }) {
         return (
           <html lang="en">
             <body className={inter.className}>
               <Providers>{children}</Providers>
             </body>
           </html>
         )
       }
       ```
       Do NOT add 'use client' to layout.tsx — it must remain a Server Component. The Providers component handles the client boundary.

    7. In `frontend/app/globals.css`, ensure Tailwind directives are present and add basic dark mode styling:
       ```css
       @tailwind base;
       @tailwind components;
       @tailwind utilities;
       ```
       Keep it minimal. RainbowKit CSS is imported in providers.tsx, not here.

    8. Verify `frontend/tsconfig.json` has path alias `@/*` configured (create-next-app should set this up). If not, add:
       ```json
       "paths": { "@/*": ["./*"] }
       ```

    9. Verify the app compiles: `cd frontend && npm run build`
