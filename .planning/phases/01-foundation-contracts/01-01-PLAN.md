<task type="auto">
  <name>Task 2: Implement WETH contract and tests</name>
  <files>
    src/tokens/WETH.sol
    test/tokens/WETH.t.sol
  </files>
  <action>
    **Create `src/tokens/WETH.sol`:**

    Implement Wrapped Ether following canonical WETH9 pattern with OpenZeppelin ERC20 + Ownable:

    - License: SPDX MIT, pragma solidity ^0.8.28
    - Inherit `ERC20("Wrapped Ether", "WETH")` and `Ownable(msg.sender)`
    - Constructor mints 1,000 WETH (1000 * 10**18) to msg.sender
    - `receive() external payable` — calls deposit()
    - `deposit() public payable` — mints msg.value WETH to msg.sender, emits `Deposit(msg.sender, msg.value)`
    - `withdraw(uint256 wad) external` — checks balance >= wad, burns WETH, sends ETH via `call{value: wad}("")` with success check. Follows CEI pattern (check balance, burn, then send ETH). Emits `Withdrawal(msg.sender, wad)`
    - `mint(address to, uint256 amount) external onlyOwner` — owner-only mint
    - `faucet(address to, uint256 amount) external` — unrestricted, calls `_mint(to, amount)` directly (no ETH required)
    - Custom events: `Deposit(address indexed dst, uint256 wad)`, `Withdrawal(address indexed src, uint256 wad)`
    - Add comment: `// WARNING: FAUCET FUNCTION — LOCAL DEVELOPMENT ONLY`

    **Create `test/tokens/WETH.t.sol`:**

    Comprehensive test contract inheriting forge-std/Test.sol:

    - setUp: deploy WETH, create labeled test addresses (owner, user1, user2), fund user1 with 10 ETH via `vm.deal`
    - Test initial state: name is "Wrapped Ether", symbol is "WETH", decimals is 18, owner balance is 1000 * 10**18, owner() returns deployer
    - Test deposit: user1 deposits 1 ETH, WETH balance increases, ETH balance decreases
    - Test receive (plain ETH transfer): user1 sends ETH directly to contract, WETH minted
    - Test withdraw: deposit then withdraw, balances correct, ETH returned
    - Test withdraw insufficient balance: expect revert with "Insufficient balance"
    - Test withdraw to contract: create a simple receiver contract to test ETH sent via call works
    - Test mint onlyOwner: owner can mint, non-owner reverts
    - Test faucet unrestricted: any user can call faucet, tokens minted without ETH
    - Test Deposit event: verify event emitted with correct indexed address and amount
    - Test Withdrawal event: verify event emitted with correct indexed address and amount
    - Test Transfer event on standard transfer: verify ERC20 Transfer event
    - Test approve and transferFrom: standard ERC20 approval flow works
  </action>
  <verify>
    `forge test --match-contract WETHTest -vv` — all tests pass.
    `forge test --match-contract WETHTest --gas-report` — shows gas usage (informational).
  </verify>
  <done>
    WETH contract deploys with 1000 WETH initial supply, 18 decimals, working deposit/withdraw for ETH wrapping, owner-only mint, unrestricted faucet, and all tests pass.
  </done>
