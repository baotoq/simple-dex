  <name>Task 1: Implement Factory contract with CREATE2 deployment and pair registry</name>
  <files>src/core/Factory.sol</files>
  <action>
Create `src/core/Factory.sol` implementing the Pool factory. Follow Uniswap V2 Factory architecture with educational comments.

**Contract structure:**
```
contract Factory is Ownable
```

**Imports:**
- `@openzeppelin/contracts/access/Ownable.sol` — owner-only pool creation (per locked decision)
- `./Pool.sol` — for CREATE2 deployment using type(Pool).creationCode

**State variables:**
- `mapping(address => mapping(address => address)) public getPair` — bidirectional lookup (per locked decision: mapping-only registry, no allPairs array)

**Events:**
```solidity
event PairCreated(address indexed token0, address indexed token1, address pair);
```

**Constructor:**
- `constructor() Ownable(msg.sender)` — deployer becomes owner (per locked decision: owner-only pool creation)

**Core function: `createPool(address tokenA, address tokenB) external onlyOwner returns (address pool)`**
- Per locked decision: owner-only pool creation
- CHECKS:
  - `require(tokenA != tokenB, "Factory: IDENTICAL_ADDRESSES")` — can't create pool for same token
  - Canonical ordering: `(address token0, address token1) = tokenA < tokenB ? (tokenA, tokenB) : (tokenB, tokenA)` (per locked decision)
  - `require(token0 != address(0), "Factory: ZERO_ADDRESS")` — neither token can be zero address
  - `require(getPair[token0][token1] == address(0), "Factory: PAIR_EXISTS")` — prevent duplicates (per locked decision)

- CREATE2 DEPLOYMENT (per locked decision):
  - Encode constructor args with creation code: `bytes memory bytecode = abi.encodePacked(type(Pool).creationCode, abi.encode(token0, token1))`
  - Compute salt from token pair: `bytes32 salt = keccak256(abi.encodePacked(token0, token1))`
  - Deploy using assembly CREATE2:
    ```solidity
    assembly {
        pool := create2(0, add(bytecode, 32), mload(bytecode), salt)
    }
    require(pool != address(0), "Factory: CREATE2_FAILED");
    ```
  - Note: Using constructor with params in creationCode (Solidity 0.8.28 pattern per research recommendation — cleaner than separate initialize() call)

- REGISTER:
  - `getPair[token0][token1] = pool` — forward lookup
  - `getPair[token1][token0] = pool` — reverse lookup (per locked decision: bidirectional)

- Emit `PairCreated(token0, token1, pool)`
- Return `pool`

**Educational comments:** Add comments explaining:
1. Why CREATE2 is used (deterministic addresses, off-chain computation)
2. Why tokens are sorted (prevents duplicate pairs with different ordering)
3. Why bidirectional mapping (convenient lookup regardless of token order)
4. How CREATE2 address is computed (factory address + salt + init code hash)
5. Why owner-only creation (controlled pool creation for this learning project)

**Do NOT include:** allPairs array, pair count tracking, feeTo/feeToSetter (Uniswap V2 protocol fee stuff), or permissionless pool creation. These are out of scope per locked decisions.
